# 力扣免费题 · C 语言题解集（第一批：100 道简单题）

> 题目与答案分开存放，文件名前缀题号一一对应，方便对照。

## 数据来源与筛选规则

- 来源：力扣中国站题题库 <https://leetcode.cn/problemset/（通过官方接口抓取，2026-10-24）>
- 只取 **免费题**（`paid_only = false`）、**难度 = 简单**、并且 **官方提供 C 语言签名** 的题
- 按 **题号升序** 排列，取前 100 道（题号 1 ~ 509）
- 已自动跳过只有 SQL / Shell 答案的题（如 175、181~~183、193、195~~197），保证每道题都有 C 代码
- 100 份 C 代码全部通过了逐文件的 C 语法解析校验（pycparser），并对溢出、边界、指针偏移等易错点做了人工推演
- 说明：本机 Windows 安全策略禁止运行未签名的 gcc，因此没有做「真实编译 + 提交」这一步，代码是按力扣 C 环境写法给出、可直接粘贴提交的；如发现个别题判错，告诉我题号，我立刻改

## 目录结构

```
leetcode_c_easy/
├── 01_题目/          # 100 份题目描述（Markdown：题意、示例、提示、官方函数签名）
├── 02_C语言答案/      # 100 份 C 代码（含思路注释）
├── README.md         # 本索引
└── _work/            # 抓取与生成用的脚本、原始 JSON（可删）
```

## 怎么用

1. 打开 `01_题目/xxx.md` 读题；
2. 打开同题号的 `02_C语言答案/xxx.c` 看思路 + 代码；
3. 在力扣编辑器里选择 **C**，把函数整体粘进去即可提交（`#include` 保留也不影响）。

每个文件开头的注释都写了算法思路和复杂度，例如：

```c
/*
 * 1. 两数之和（简单）
 * https://leetcode.cn/problems/two-sum/
 *
 * 思路：哈希表。一边遍历一边把「数值 -> 下标」存进哈希表……
 * 时间复杂度 O(n)，空间复杂度 O(n)。
 */
```
